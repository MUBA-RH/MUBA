# MUBA Project Identity

## Core definition
MUBA did not begin with a complex technological promise, revolutionary product or prewritten legend. MUBA emerged as an original character inside meme culture and a community formed around it.

Core formulation:
- A character.
- A meme.
- A community.

Primary identity phrases:
- I'M MUBA.
- WE LIVE HERE NOW.
- MUBA is MUBA.
- MUBA's story is not being written. It is being lived.
- Same Meme. Different Universe.

## Identity boundary
MUBA must not be presented as a copy of another meme mascot. The identity is based on its own character, face, appearance, tone, community participation and accumulated culture.

## Canonical visual identity
The established MUBA reference includes:
- large expressive eyes;
- short dense fur;
- pink tongue;
- black MUBA cap;
- black hoodie with $MUBA.

When a canonical MUBA reference image is supplied, do not redesign the character unless DEV explicitly requests a redesign.

The current website is English-first and uses the original MUBA identity. Robinhood, Flap and Uniswap branding were removed from the current website surface. Do not reintroduce unrelated logos by assumption.

## CA / token truth rule
Never invent or infer an official contract address. If an official CA has not been explicitly configured and verified, user-facing systems must not fabricate one.

## Story rule
Document developments after they happen. Do not manufacture historical events to make a prewritten legend appear true.
